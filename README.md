# Rajesh R G Portfolio

A premium dark-theme enterprise portfolio built with Next.js App Router, TypeScript, Tailwind CSS, and lucide-react.

## Sections

- Hero
- About Me
- Core Expertise
- Professional Experience
- Certifications
- Featured Projects
- Contact

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run start
```
